# 多线程下载 2.1.1

本版恢复 1.x 的 aria2 下载引擎，保留新版交互。

## 安装

先完成或取消旧扩展中的下载，然后关闭旧扩展。解压完整工程，在 Windows 安装 Python 3，双击 install.cmd。安装脚本下载并校验 aria2 官方文件、准备 64 路引擎并注册本机桥接。

Chrome 打开 chrome://extensions/，启用开发者模式，加载工程内包含 manifest.json 的 extension 文件夹。面板底部应显示版本 2.1.0，顶部显示 aria2 已连接。

2.0.x 与本版扩展 ID 不同。请关闭旧版自动接管，并刷新已打开的下载网页。切换前的下载分片不能直接迁移。移动工程后重新运行 install.cmd。

## 使用

- 正常点击网页文件下载，或右键直链选择“使用多线程下载”。
- 点击后即时反馈；带操作按钮的提示横排显示，并在 8 秒圆环倒计时结束后关闭。
- 在扩展设置选择文件夹或输入完整路径；已有下载保持原目录。
- 支持 4/8/16/32/64 路，默认 8。速度显示恢复 1.1.4 的默认方式：直接读取 aria2 的 `downloadSpeed`，约每 1.5 秒刷新；连接中不显示瞬时速度，暂停时也不显示人为的 0 B/s。
- 支持暂停、继续、取消和切回 Chrome；完成或取消后清理任务记录及对应临时文件。

接管时 Chrome 原任务暂停，作为失败回退。请在扩展面板看进度。代理沿用 1.x 的设置读取方式，不能保证与纯浏览器网络路径完全一致；比较速度时应使用同一代理线路。

## 边界

小文件、带登录认证的自动下载、POST、Blob、无痕和危险下载保留给 Chrome。右键不会复制登录凭据。并发数是上限，实际连接数和速度受服务器、线路、文件大小影响。

不要删除正在下载的临时分片。完全退出浏览器后，引擎可能继续运行；重新打开扩展会尝试核对原任务状态。升级、切换引擎或移动目录前应结束当前任务。

## 卸载与许可

从 Chrome 移除扩展，再运行工程中的 uninstall.ps1，可停止本机引擎并注销桥接，不删除正式下载文件。
